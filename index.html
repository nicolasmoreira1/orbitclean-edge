01

O problema

Hoje, quando um satélite detecta um detrito próximo, os dados precisam ir até uma estação no solo, ser processados e voltar como comando de manobra. Esse processo leva minutos.

Em órbita baixa, satélites viajam a 28.000 km/h. Minutos de atraso são tempo demais para evitar uma colisão.

27.000+ detritos catalogados em órbita
28.000 km/h velocidade típica em LEO
> 400ms latência mínima solo-satélite
02

A tecnologia

A ideia é simples: tirar a decisão do solo e colocar dentro do satélite.

Detecção local

O sensor lê a distância de objetos próximos a cada 50ms, sem depender de sinal externo.

Decisão embarcada

O software calcula o melhor vetor de evasão em milissegundos, direto no hardware do satélite.

Rede em malha

O novo vetor é propagado para os satélites vizinhos, que se recalibram automaticamente.

Arduino Uno R3 Sensor HC-SR04 Servo Motors x2 Sensor TMP36 LCD 16x2 C++ Embarcado Python + Matplotlib JavaScript

Objetivos

01

Evasão em tempo real

Auditoria humana

06

Aplicação no dia a dia

O operador no solo deixa de agir em emergências e passa a auditar relatórios.

  1. Detecção

    O sensor lê a proximidade de detritos continuamente. Abaixo de 100cm, o alerta é acionado.

  2. Cálculo do vetor

    O software calcula a manobra de menor custo em combustível e aciona os propulsores.

  3. Propagação em malha

    O novo vetor é enviado para os satélites vizinhos, que se recalibram automaticamente.

  4. Log enviado ao solo

    A telemetria da manobra chega ao dashboard para o engenheiro revisar depois.

  5. Modelagem de risco

    O script Python gera o gráfico N(t) = N0 * e^(kt) mostrando o crescimento projetado dos detritos.
